# 🎬 Quaint Animation Films

> A curated collection of animated short films by Quaint Animation Films.

[![Website](https://img.shields.io/badge/Website-qanimation.it-black?style=flat-square)](https://qanimation.it)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=flat-square\&logo=github)](https://github.com/kathegrima/Q.ANIMATION-FILMS)

**Quaint Animation Films** is a lightweight, responsive website showcasing a collection of animated films and their visual artwork.

The project is intentionally simple: a static front-end built with HTML and CSS, with no framework or build system required.

## ✨ Features

* 🎞️ Collection of animated films
* 🖼️ Dedicated poster artwork for each film
* 📱 Responsive web design
* 🎨 Custom visual identity and typography
* 🌐 Static website with minimal dependencies
* 📲 Web App Manifest support
* 🔖 Custom favicon and application icons

## 🎥 Featured Films

The current collection includes:

* **Dattilo**
* **Drop**
* **Fluco**
* **Halloween**
* **Itala**
* **Silver**
* **Stella**
* **Vaya**

Each film is represented through dedicated poster artwork integrated into the website.

## 🛠️ Tech Stack

The project uses a deliberately minimal stack:

| Technology       | Purpose                           |
| ---------------- | --------------------------------- |
| HTML5            | Website structure                 |
| CSS3             | Layout and visual styling         |
| Custom Web Fonts | Typography and visual identity    |
| Web App Manifest | Progressive Web App metadata      |
| Static Assets    | Posters, logos, icons and artwork |

No JavaScript framework, package manager or compilation step is required.

## 🎨 Design Philosophy

The website follows a visual-first approach.

The goal is not to introduce unnecessary technical complexity, but to let the films and their artwork remain the primary focus.

The implementation therefore relies on:

* semantic HTML
* CSS-based layout and styling
* locally hosted assets
* custom typography
* responsive design

This makes the project lightweight, portable and easy to maintain.

## 🔧 Development

There are no external dependencies to install.

To modify the website:

1. Edit `index.html` to change the content and structure.
2. Edit `stylesheet.css` to change the visual design.
3. Replace or add poster assets as needed.
4. Test the website across desktop and mobile screen sizes.

## 📱 Progressive Web App

The repository includes a Web App Manifest and multiple application icons, allowing the website to provide metadata suitable for installation and improved integration with supported browsers and devices.
